# KOKORIN WEB

Сайт-портфолио: сайты и автоматизация для бизнеса. Next.js 16, React 19,
Tailwind v4, без внешних UI-библиотек.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить, если нужны заявки в Telegram
npm run dev                  # http://localhost:3000
```

Без `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` сайт и форма работают полностью,
а заявка пишется в лог сервера — сайт не должен падать из-за незаполненной
переменной окружения.

## Где что лежит

| Что | Где |
| --- | --- |
| **Весь текст сайта** | `src/content/site.ts` |
| Дизайн-система (палитра, типографика, кривые) | `src/app/globals.css` |
| Живое поле первого экрана (WebGL) | `src/components/IrisField.tsx` |
| Стена превью (DriftWall из React Bits) | `src/components/DriftWall.tsx` |
| Приём заявки | `src/app/api/brief/route.ts` + `src/lib/brief.ts` |
| Превью проектов | `public/shots/*.svg`, генератор — `scripts/make-previews.mjs` |

**Тексты правятся только в `src/content/site.ts`.** В компонентах строк нет,
поэтому разъехаться им негде. Места, которых не было в исходном тексте,
помечены комментарием `ЧЕРНОВИК:` — их стоит перечитать и заменить своими
формулировками. Таких мест семь: пять ответов FAQ (на исходном сайте они
свёрнуты и в разметку не попадают), подсказка в поле брифа и тексты состояний
отправки формы.

## Структура страницы

Порядок блоков повторяет `ilyalanding.ru`: первый экран → услуги → кейсы →
подборка превью → процесс → обо мне → FAQ → бриф → контакты. Нумерация секций
приведена к сквозной `01…08`: в исходнике она сбита (два блока под номером 07,
номера 01 и 06 пропущены), а номер показан как позиция в последовательности,
то есть сообщает читателю, где он находится.

Подборка превью — отдельный блок, которого на исходном сайте нет.

## Шрифты

- **Akt** (Дмитрий Гренев) — дисплейная гарнитура, переменная ось веса 100–900.
- **Golos Text** (Александра Королькова) — текст и интерфейс.

Обе кириллические, обе подключены через `next/font/google` и раздаются со
своего домена. Третьей гарнитуры нет: акцент делается весом и кеглем.

Сборка печатает предупреждение `Failed to find font override values for font
Akt` — у Next нет метрик этой гарнитуры для автоматического fallback. В
`--font-display` подставлен `Arial Narrow` как ближайший по пропорциям.

## Анимация

Один опорный момент — поле в первом экране. Это не градиенты: высотное поле
строится domain-warped FBM, из него берутся нормали, и по ним считается
иридескентное затенение с френелевской развёрткой, поэтому масса читается
объёмом и по-разному окрашивается в зависимости от угла. Поле реагирует на
курсор и уходит вглубь при скролле.

Остальное движение служебное: появление смысловых групп при входе в кадр,
состояния наведения, раскрытие FAQ. Контент виден по умолчанию — если скрипт
не выполнится, страница останется целой.

`prefers-reduced-motion` обработан везде: поле показывает статичный кадр,
стена превью замирает, появление секций сводится к проявлению без сдвига.

## Превью проектов

`public/shots/*.svg` — нарисованные миниатюры композиций, а не скриншоты
реальных сайтов; так и подписано в блоке подборки. Каждая собрана в палитре
своего кейса. Перегенерировать:

```bash
npm run previews
```

Когда появятся настоящие скриншоты, их можно положить туда же под теми же
именами и убрать подпись из `gallery.note`.
