# РусМебель — мебель на заказ в Щёлково

Одностраничный сайт мебельной компании из Щёлково: каталог направлений,
помощник, который собирает заявку вопросами, и один канал связи — WhatsApp,
где компания реально отвечает.

## Что внутри

| Часть | Где | Что делает |
| --- | --- | --- |
| Лендинг | `src/app/page.tsx` | Герой, каталог из 5 направлений, витрина работ, заявка, контакты |
| ИИ-помощник | `src/components/BriefChat.tsx` + `src/app/api/brief` | Задаёт вопросы и через tool use складывает ответы в бриф |
| Обычная форма | `src/components/BriefForm.tsx` | Тот же бриф для тех, кто не хочет переписываться |
| Графика | `src/components/Art.tsx` | Все иллюстрации — свой SVG, ни одного внешнего запроса |

Ключевая идея: **реквизиты заданы ровно в одном месте** — `src/lib/company.ts`.
Шапка, контакты, футер, все ссылки WhatsApp и системный промпт ИИ читают их
оттуда. Разделы каталога так же живут только в `src/lib/catalog.ts`, а формат
заявки — в `src/lib/brief.ts`. Телефону негде разъехаться между шапкой и
подвалом, потому что он там один.

## Запуск

```bash
npm install
cp .env.example .env.local   # ключ не обязателен, см. ниже
npm run dev                  # http://localhost:3000
```

## Как устроена заявка

Заявка никуда не отправляется на сервер, и это осознанно: у компании в
проверенных источниках нет ни Telegram, ни почты, а лид, который никто не
прочитает, хуже отсутствия формы. Оба пути — помощник и форма — собирают один
и тот же объект `Brief` и превращают его в готовое сообщение WhatsApp:

```
Здравствуйте! Заявка с сайта.

Нужна: Кухни
Помещение: кухня 9 м², новостройка
Размеры: прямая 3,2 м, потолок 2,7
Телефон: +7 900 000-00-00
```

Человек нажимает кнопку, открывается WhatsApp с уже набранным текстом —
остаётся отправить.

### Помощник без ключа

Без `ANTHROPIC_API_KEY` сайт работает целиком, а помощник переключается на
сценарий из `SCRIPT_STEPS` в `src/lib/brief.ts`: те же поля, только вопросы
заданы заранее. Ничего не ломается и не показывает заглушку — демо можно
открыть на любом ноутбуке. С ключом помощник ведёт живой диалог, сам решает,
что уточнить, и записывает ответы инструментом `update_brief`.

Помощник намеренно **не консультант**. В `src/lib/company.ts` есть список
`UNKNOWNS` — цены, сроки, материалы, условия замера, гарантия. Всё это
попадает в системный промпт как прямой запрет: спросили — честно отвечает, что
считает менеджер, и не называет ни одной цифры.

## Фотографии

Своих снимков у компании в открытых источниках нет, поэтому вся графика
нарисована в SVG и страница выглядит законченной без единой фотографии.

Когда настоящие фото появятся, их достаточно положить в `public/photos` с
нужными именами — иллюстрации заменятся сами, без правок в коде. Список имён
и пропорции — в `public/photos/README.md`.

## Откуда данные

Адрес, часы работы, телефон и список направлений взяты из
[карточки компании в Яндекс Картах](https://yandex.ru/maps/org/rusmebel/206020341868/)
и [справочника Щёлково](https://shchelkovo.spravker.ru/org/rusmebel.htm).

Чего на сайте сознательно нет, потому что этого нет в проверенных источниках:
цен, сроков, материалов, условий замера и дизайн-проекта, гарантии, отзывов.
Единственный отзыв в карточке оставлен в 2020 году другим мебельным ателье —
выдавать его за свежий отзыв частного клиента было бы враньём.

Витрина «Что делаем» называет **типы работ**, а не выполненные объекты: пока
нет подтверждённых фотографий проектов, приписывать компании конкретные
объекты нельзя.

## Статика для показа по ссылке

```bash
npm run export   # соберёт out/
```

Собирает сайт без сервера: помощник в этой сборке работает по заранее
заданным вопросам, ключ не нужен. Сборка помечается как демонстрационная —
в подвале появляется строка «не официальный сайт компании», а страница
закрывается от поисковиков через `noindex`. В обычной сборке
(`npm run build`) этой пометки нет: она нужна ровно для макета, который
показывают по ссылке до согласования с компанией.

Папку `out/` можно положить на любой статический хостинг.

## Проверка

```bash
npm run typecheck
npm run build
```

Разметка проверена по [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines):
семантические теги, видимый фокус, метки у всех полей, `aria-live` на живых
обновлениях, поддержка `prefers-reduced-motion`, безопасные зоны на телефоне,
явные размеры у картинок.

## Деплой на Vercel

Обычное Next.js-приложение, Vercel определяет его сам. По шагам:

1. **vercel.com → Add New → Project → Import** репозиторий `kokorinweb/kokorin1`.
2. **Сразу после импорта смените ветку.** Веткой по умолчанию в репозитории
   стоит старое демо ресторана, и Vercel соберёт именно его:
   *Settings → Git → Production Branch* → `claude/upbeat-albattani-gdleul` →
   Save, затем *Deployments → Redeploy*.
   Альтернатива, если не хочется возвращаться к этому при каждом проекте: на
   GitHub в *Settings → Branches* сделать эту ветку веткой по умолчанию — тогда
   импорт заработает сразу.
3. **Settings → Environment Variables:**

   | Переменная | Значение | Зачем |
   | --- | --- | --- |
   | `ANTHROPIC_API_KEY` | ключ из console.anthropic.com | Включает живой ИИ-помощник вместо сценария |
   | `NEXT_PUBLIC_DEMO` | `1` | Пометка «демонстрационный макет» и `noindex` |

   Без первой переменной сайт работает целиком, помощник просто идёт по
   заранее заданным вопросам.

4. **Адрес.** Vercel выдаёт что-то вроде `kokorin1-a1b2c3.vercel.app`. В
   *Settings → Domains* поддомен переименовывается в свободный — например
   `rusmebel.vercel.app`. Туда же подключается собственный домен, если он есть.

### Про `NEXT_PUBLIC_DEMO`

Пока это макет, показанный компании до согласования, флаг стоит держать
включённым. Он делает две вещи: закрывает страницу от поисковиков и добавляет
в подвал строку о том, что это макет, а не официальный сайт компании. Контакты
на странице настоящие, и посторонний человек не должен принять её за сайт
«РусМебели». Когда компания согласится и сайт встанет на свой домен —
переменную убираете, и пометки нет.

## Другие способы

Статика из `npm run export` кладётся на любой статический хостинг, включая
GitHub Pages (в сборку кладётся `.nojekyll`). Живого ИИ-помощника там не будет:
серверного роута в статике нет.
