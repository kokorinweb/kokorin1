# Картинки сайта

Папка пустая намеренно: сайт работает без единой фотографии — вместо кадра герой рисует
градиент. Как только файл появится здесь, он подхватится сам, править код не нужно.

| Файл | Где появится | Что снимать |
| --- | --- | --- |
| `hero.jpg` | Фон первого экрана главной | Горизонтальный кадр зала или печи, тёмный и плотный: поверх него лежит крупный текст. От 2400 px по ширине. |

Механика — в `src/lib/assets.ts`: сервер проверяет наличие файла и отдаёт `src` только если
он реально есть. Поэтому в консоли никогда не будет 404 за ненайденную картинку.

Важно: проверка происходит при сборке страницы, так что после добавления файла нужен
пересобранный деплой (`npm run build`), а в `npm run dev` достаточно обновить вкладку.
