# Фотографии

Сюда кладутся настоящие снимки. Пока каталог пуст, на сайте рисуются
иллюстрации из `src/components/Art.tsx` — страница выглядит законченной и
без фотографий.

Подходят `.avif`, `.webp`, `.jpg`, `.png`. Имя файла определяет, куда встанет
снимок; расширение любое из перечисленных.

## Разделы каталога

| Файл | Куда встанет |
| --- | --- |
| `kitchens.jpg` | Карточка «Кухни» |
| `wardrobes.jpg` | Карточка «Шкафы-купе» |
| `cabinet.jpg` | Карточка «Корпусная мебель» |
| `glass.jpg` | Карточка «Мебель из стекла» |
| `panels.jpg` | Карточка «Стеновые панели» |

## Витрина «Что делаем»

| Файл | Куда встанет |
| --- | --- |
| `work-1.jpg` | Кухня под потолок |
| `work-2.jpg` | Шкаф в нишу |
| `work-3.jpg` | Стеклянная перегородка |
| `work-4.jpg` | Стеллаж и рабочее место |
| `work-5.jpg` | Реечная стена |
| `work-6.jpg` | Гардеробная комната |

Пропорции карточек: 4:3, у крупной карточки «Кухни» — 16:9. Снимки
обрезаются по центру (`object-fit: cover`), так что главное держите в центре
кадра. Разумный размер — 1600 px по длинной стороне.

После добавления файлов нужна пересборка (`npm run build`): список
существующих фотографий читается один раз, при сборке.
