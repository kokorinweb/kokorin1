# Сбор заведений без сайта из 2ГИС

Два скрипта. Оба на голых `requests` + `pandas`, без фреймворков.

| Файл | Что делает | Когда использовать |
| --- | --- | --- |
| `dgis_venues.py` | Официальный Catalog API 2ГИС | Всегда |
| `dgis_venues_scraper.py` | Парсинг публичных страниц `2gis.ru` | Практически никогда, см. предупреждение |

## Быстрый старт

```bash
pip install -r scripts/dgis/requirements.txt
export DGIS_API_KEY="ваш_ключ"          # PowerShell: $env:DGIS_API_KEY="..."
python scripts/dgis/dgis_venues.py --city "Новосибирск" --category кафе --category бар
```

На выходе `dgis_no_website.csv` в UTF-8 с BOM — Excel открывает двойным кликом,
кириллица не рассыпается.

## Ключ и лимиты

Заявка на ключ: <https://dev.2gis.ru/order/>, личный кабинет и статистика —
<https://partner.api.2gis.ru/>, документация — <https://docs.2gis.com/ru/api/search/places/overview>.
Точные квоты зависят от тарифа и видны только в кабинете; на бесплатном доступе
часть полей (в первую очередь `items.reviews` — рейтинг и отзывы) может быть
недоступна, скрипт это переживает и просто оставляет колонки пустыми.

Отдельно: 2ГИС ограничивает **глубину одной выдачи**. «Все кафе города» одним
запросом не выкачиваются — API перестаёт отдавать результаты задолго до `total`.
Скрипт честно пишет в лог «получено N из M». Лечение — дробить запрос:
добавлять узкие рубрики (кофейня, столовая, пиццерия, кальянная) и/или гонять
по районам: `--category "кафе Октябрьский район"`.

## Что именно попадает в выгрузку

Организация проходит фильтр, если **поле сайта пустое** и есть **телефон или
соцсеть**. Две настройки в `CONFIG` этот фильтр меняют:

- `social_link_is_not_a_website` (по умолчанию `True`) — если в поле «сайт» стоит
  `vk.com`, `t.me`, `taplink` или агрегатор, сайта считай что нет, ссылка
  переезжает в колонку соцсети. Это и есть основная целевая аудитория.
- `count_email_as_contact` (по умолчанию `False`) — по ТЗ e-mail за способ связи
  не считается. Флаг `--email-is-contact` включает.

Дедупликация — по нормализованной паре «название + адрес» (регистр, кавычки, «ё»,
лишняя пунктуация игнорируются).

## Про парсер сайта

`dgis_venues_scraper.py` требует явный флаг `--i-understand-the-risks` и печатает
предупреждение. Коротко, почему это плохой путь: нарушение ToS сайта, реальный
риск бана IP (включая браузер на той же машине), и главное — `2gis.ru` рисует
карточки на JavaScript, так что голым `requests` данных часто просто нет.
Ротация прокси и обход капчи там сознательно не реализованы.
