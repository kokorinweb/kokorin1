# Визуальная система Osteria Bellini

Документ описывает, что уже реализовано в коде, и служит границей: менять эти решения можно,
«случайно разойтись» с ними — нет. Токены живут в `src/app/globals.css`, больше нигде цвета
не задаются.

## Поверхности

| Токен | Значение | Где |
| --- | --- | --- |
| `plaster` | `#e8eadf` | Фон страницы. Известковая штукатурка с оливковым подтоном |
| `plaster-dark` | `#dbdfd0` | Границы, разделители, неактивные плашки |
| `shell` | `#f3f5ec` | Карточки и поля ввода — светлее страницы, не белые |
| `basil` / `basil-dark` | `#2f5d3f` / `#23472f` | Тёмные секции, кнопки действия, герой |
| `terracotta` | `#a83f28` | Цены и единственный акцент. Не для больших плоскостей |
| `ink` / `ink-soft` | `#221d17` / `#5c534a` | Текст на светлом |

Кремовый `#fbf7f0`, с которого начинался проект, убран намеренно: тёплый off-white стал
рефлекторным выбором ИИ-генерации и ничего не сообщает о заведении. Оливковый подтон растёт
из зелени вывески.

## Светлое на цветном

Нейтральный светлый текст поверх цвета читается как «серый по цвету»: тускло и будто
случайно. Поэтому у каждой цветной поверхности свой светлый тон.

| Токен | Значение | На чём лежит |
| --- | --- | --- |
| `on-basil` | `#e9f2e4` | Основной текст и светлые плашки на зелёном |
| `on-basil-soft` | `#c1d4bb` | Вторичный текст на зелёном, контраст 4.5:1 |
| `on-terracotta` | `#fdeee6` | Текст на терракотовых кнопках |

Прозрачность для приглушения текста не используется: `opacity` перемножается по всей цепочке
родителей, и предсказать итоговый контраст нельзя. Приглушённый тон задаётся своим значением.

## Типографика

- Дисплейная — Cormorant Garamond, включая настоящий курсив: им набраны акценты в манифесте.
- Текстовая — Manrope.
- Заголовок первого экрана: `clamp(2.25rem, 10.5vw, 12rem)`, интерлиньяж `0.92`, трекинг `-0.03em`.
  Две строки, подобранные так, чтобы не переноситься ни на 390 px, ни на 1680 px.
- Прописными — только короткие подписи. Строка длиннее ~30 знаков капителью не набирается.

## Движение

Один авторский момент на страницу, а не одинаковое появление у каждой секции.

- **Первый экран** — липкий кадр: фон приближается (scale 1 → 1.4), заголовок уезжает и гаснет,
  снизу наезжает панель манифеста. Это и есть тот самый момент.
- **Манифест** своей анимации не имеет: его приезд и есть движение.
- **Сетка «Рекомендуем»** — единственное вспомогательное появление, сдвиг на 14 px по очереди.
- Появление блоков **не использует прозрачность**. Блок с `opacity: 0` невидим для всех, у кого
  не отработал JS: поисковика, детектора вёрстки, сервиса скриншотов.
- Общая кривая — `cubic-bezier(0.22, 1, 0.36, 1)`, задана один раз в `src/components/motion/Stagger.tsx`.
- `prefers-reduced-motion` убирает не только анимации, но и разгон скролла с перекрытием.

## Иконки

Свой набор в `src/components/icons.tsx`: один `viewBox 24`, одна толщина штриха, `currentColor`.
Эмодзи как иконки не используются — их рисует операционная система, поэтому в каждой они разной
толщины, цвета и не попадают ни в какую сетку.

## Сенсорные зоны

Любой самостоятельный контрол — не меньше 44 px по высоте касания. Проверяется замером
`getBoundingClientRect()` на ширине 390 px; ссылки внутри абзаца под правило не попадают.

## Чем проверяется

```bash
npm run build && npm run start
IMPECCABLE_BROWSER=<путь к chromium> \
  .claude/skills/impeccable/scripts/impeccable detect \
  http://localhost:3000/ http://localhost:3000/menu http://localhost:3000/cart
```

Ноль срабатываний — текущее состояние и условие для правок. Скилл лежит в `.claude/skills/`.
