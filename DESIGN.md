# Design

Два мира в одном приложении, и это осознанно.

**Витрина** (`src/app/(site)`) — режим Persuade: кремовая бумага, антиква Cormorant
Garamond, базилик и терракота. Гость должен захотеть поесть. Этот мир не меняется.

**Панель заказов** (`src/app/admin`) — режим Operate: владелец в задаче, а не в
впечатлении. Здесь интерфейс обязан исчезать за работой: сканируемость, привычные
элементы, одинаковый словарь на всех экранах. Бренд живёт в точных деталях, а не в
декоре.

## Свет, а не тема

Панель светлая, одна тема, без тёмных плашек — по требованию владельца и по сцене
использования: ноутбук в зале или кабинете при обычном дневном свете, иногда телефон в
час пик. Тёмных поверхностей нет нигде: ни рельсы, ни залитых плиток, ни чёрных кнопок и
подсказок. Тёмный остаётся только у текста — это контраст, без него не читается.

## Токены

Заданы в `src/app/globals.css` (блок `@theme`), панель использует только их.

| Роль | Значение | Где |
| --- | --- | --- |
| `panel` | `#f6f5f1` | фон приложения, тёплый off-white |
| `surface` | `#ffffff` | карточки, таблицы |
| `surface-2` | `#fbfaf6` | рельса и тулбары — теплее контента |
| `tint` | `#f1efe8` | шапки таблиц, hover, мягкие заливки |
| `line` | `#e6e2d8` | волосяные границы |
| `ink` | `#262119` | основной текст, 15.9:1 на карточке |
| `ink-soft` | `#655c4d` | второстепенный текст, 6.6:1 |
| `ink-muted` | `#756c5d` | подписи и плейсхолдеры, 5.2:1 (порог 4.5) |
| `accent` | `#2f7d55` | первичные действия, текущий выбор, полосы графика |
| `accent-strong` | `#256345` | текст акцента на светлой заливке |
| `accent-tint` | `#e6f1ea` | заливка акцента |

Нейтрали тёплые, а не серые: они уводят в кремовую сторону витрины, поэтому панель
выглядит частью того же заведения, а не чужой админкой.

## Семантика состояний

Один статус — один цвет, заданный в `src/lib/status.ts` и больше нигде.

| Статус | Заливка / текст |
| --- | --- |
| Новый | `warn-tint` / `#a8452c` |
| Принят | `gold-tint` / `#8a6316` |
| Готовится | `violet-tint` / `#54398f` |
| В пути, Готов к выдаче | `blue-tint` / `#1f5580` |
| Выдан | `accent-tint` / `accent-strong` |
| Отменён | `tint` / `ink-muted` |

Каждая пара проверена на контраст (минимум 4.9:1). Цвет никогда не единственный канал:
рядом всегда подпись, а в графиках — число.

## Типографика

Одна гарнитура — Manrope. Антиква в панели не используется: витринная антиква в кнопках,
подписях и данных — это костюм, а не иерархия. Шкала фиксированная в rem, шаг ~1.2:
`0.6875` подписи · `0.8125` текст · `0.9375` заголовки карточек · `1.375` заголовок
экрана · `1.875` крупные числа. Цифры в таблицах и плитках — `tabular-nums`, крупные
числа — пропорциональные.

## Композиция

Слева рельса с подписями (шесть разделов — иконки без подписей уже не читаются), справа
колонка: заголовок экрана, затем содержимое. Заголовок несёт только имя экрана и его
состояние; надстрочных кикеров нет.

Сетка: карточки одного уровня, без вложенных карточек. Плитки показателей — ряд наверху,
дальше рабочая область. Таблица на узком экране превращается в карточки, а не в
горизонтальную прокрутку: на телефоне статус должен быть под пальцем.

## Поведение

- Переходы 150–200 мс, только на смену состояния и наведение. Никаких входных
  анимаций страницы: панель открывается в задаче.
- Один авторский момент: строка заказа, у которой только что сменили статус, коротко
  подсвечивается — глаз находит её после действия.
- Загрузка — скелетоны той же формы, что и содержимое, не спиннеры.
- Выпадающие меню позиционируются `fixed` от координат кнопки: внутри таблицы с
  горизонтальной прокруткой абсолютное меню обрезается.
- Пустые состояния объясняют, что сделать, а не сообщают «ничего нет».
- Браузерные поверхности тоже наши: выделение текста, каретка, полосы прокрутки и
  фокусные рамки покрашены токенами.

## Графики

Палитра категорий прогнана валидатором на различимость при дальтонизме; порядок слотов
менять нельзя (`src/components/admin/palette.ts`). Один ряд — один цвет и никакой
легенды. Сетка — сплошные волосяные линии. Значения читаются с оси, подписи максимума и
из таблицы под графиком, а не только из подсказки на наведении.
