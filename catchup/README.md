# Догоняй

Telegram-бот, который пересказывает групповые чаты. Вернулся вечером, а там 600 сообщений —
бот отдаёт сводку дня, а персонально каждому участнику — то, что касается лично его.

## Из чего состоит

| Часть | Где | Что делает |
| --- | --- | --- |
| Бот | `src/bot/bot.ts` | Команды, запись сообщений, оплата через Stars |
| Сводки | `src/lib/digest.ts` | Вызов модели со структурированным ответом, потолки расхода |
| Хранилище | `src/lib/db.ts`, `src/lib/repo.ts` | SQLite из стандартной библиотеки Node, без зависимостей |
| Вебхук | `src/app/api/telegram` | Приём апдейтов от Телеграма |
| Лендинг | `src/app/page.tsx` | Страница бота и описание работы с данными |

## Модель денег

Общая сводка (`/svod`) — раз в сутки на чат бесплатно. Персональная (`/me`) — за кредит;
кредиты покупаются пакетами за Telegram Stars. Новому человеку даётся 3 бесплатных,
чтобы он увидел ценность до того, как его попросят заплатить.

Stars выбраны сознательно: не нужно ни юрлица, ни эквайринга, ни договора с банком.
Телеграм собирает деньги сам.

Виральность встроена в механику: сводка появляется в общем чате, её видят все участники,
и бот расходится по их чатам без рекламы.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить токен и ключ
npm run smoke                # проверка логики без обращения к модели
npm run dev                  # сайт на http://localhost:3000
npm run bot                  # в отдельном терминале: бот через long polling
```

**Обязательный шаг:** в @BotFather выключить privacy mode (`/setprivacy` → Disable).
Иначе бот получает только команды и упоминания, а сводки выходят пустыми. Это самая
частая причина «бот не работает».

## Деплой

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://ваш-домен/api/telegram&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

Отдельный процесс для бота не нужен — он живёт в том же приложении.

Удаление просроченных сообщений повесить на расписание:

```bash
curl -H "Authorization: Bearer $CATCHUP_CRON_SECRET" https://ваш-домен/api/cleanup
```

## Деньги на токенах

Сводка длинного чата — это реальные деньги за входные токены, поэтому потолки стоят
до обращения к API, а не после:

- `CATCHUP_MAX_CHARS` и `CATCHUP_MAX_MESSAGES` режут транскрипт (берётся свежий хвост);
- `CATCHUP_DAILY_TOKEN_CAP` — суточный предел на чат, после него сводки отключаются до завтра;
- расход пишется в `usage_daily` по каждому чату.

Кэш промпта включён только для персональных сводок: там один и тот же транскрипт уходит
повторно, когда несколько человек одного чата догоняют одно окно. Для единственной дневной
сводки запись в кэш была бы чистой переплатой, поэтому её там нет.

Модель по умолчанию — `claude-opus-5` ($5/$25 за 1M токенов). Дешевле, если качество
сводки устроит: `claude-sonnet-5` ($2/$10), `claude-haiku-4-5` ($1/$5).

## Данные

Хранятся только текстовые сообщения чатов, куда бота добавили, срок — `CATCHUP_RETENTION_DAYS`
суток. `/forget` в чате (для админов) стирает историю немедленно. Медиа, голосовые и личная
переписка не сохраняются.

## Чего здесь осознанно нет

Это работающий MVP, а не готовая к нагрузке система.

- **База — файл на диске.** На Vercel и любом serverless с эфемерной файловой системой она
  исчезнет между запусками. Деплоить нужно туда, где есть постоянный диск: VPS, Fly.io с
  volume, Railway. Это первое, что придётся менять при росте.
- **Один инстанс.** Несколько реплик над одним SQLite-файлом работать не будут.
- **«Прочитано» — эвристика.** Bot API не отдаёт отметок о прочтении, поэтому за точку
  отсчёта берётся последнее собственное сообщение участника. Человек, который читает, но
  не пишет, получит сводку за слишком долгий период.
- **Только текст.** Картинки, голосовые, файлы, опросы и пересланные сообщения не попадают
  в сводку.
- **Правки и удаления игнорируются.** Отредактированное сообщение останется в базе в исходном виде.
- **Нет авто-сводок по расписанию.** Только по команде.
- **Нет возвратов Stars.** `refundStarPayment` не подключён; возврат придётся делать руками.
- **Нет метрик и админки.** Сколько чатов, сколько платят, какая конверсия — считать пока нечем,
  а без этого непонятно, растёт оно или нет.
