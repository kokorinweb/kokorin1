# Сифон

Промо-лендинг вымышленной газировки «Сифон». Статическая страница без сборки:
открывается двойным кликом по `index.html`, кладётся на любой хостинг как есть.

```
sifon/
├── index.html              вся разметка страницы
└── assets/
    ├── css/style.css       дизайн-токены и все секции
    ├── js/main.js          прелоадер, скролл-хореография, автомат
    └── vendor/             gsap 3.13, ScrollTrigger, lenis 1.3 — локально, без CDN
```

## Идея

Бренд построен вокруг уличного автомата газированной воды: бирюзовая эмаль корпуса,
алая кнопка, латунная монета, этикеточная бумага и стекло гранёного стакана. Отсюда
и палитра, и интерактивная секция «Автомат», и цена «3 коп.» на бейдже.

Пять вкусов — тархун, барбарис, дюшес, саяны, крем-сода — задают акцентные цвета,
которые перекрашивают секцию вкусов прямо во время горизонтального скролла.

## Что происходит при скролле

| Секция | Механика |
| --- | --- |
| Прелоадер | счётчик 0→100, заливка полосы, шторка уезжает вверх |
| Герой | побуквенный выход логотипа, параллакс бутылки, наклон за курсором, канвас с пузырьками |
| Манифест | секция пинится, три тезиса сменяют друг друга, контурная бутылка поворачивается по прогрессу |
| Вкусы | пин + горизонтальная лента из пяти карточек, фон перекрашивается в цвет текущего сиропа |
| Факты | счётчики добегают до значений при появлении в кадре |
| Автомат | монета → выбор сиропа → струя и наполнение гранёного стакана |
| Акция | обратный отсчёт до 31 декабря, проверка кода с крышки |
| Отзывы | две встречные бегущие строки |
| Финал | побуквенный выход крупной надписи, параллакс подписи в подвале |

## Доступность и отказоустойчивость

- `prefers-reduced-motion: reduce` выключает всю хореографию: пин, горизонтальный
  скролл и прелоадер отменяются, секции разворачиваются в обычный вертикальный поток.
- Без JavaScript страница остаётся полностью читаемой — ничего не спрятано за
  наблюдателями скролла, весь контент виден в покое.
- Клавиатурная навигация: у всех интерактивных элементов видимый фокус, у кнопок
  автомата — `aria-pressed`, у статуса автомата и форм — `aria-live`.
- Горизонтального скролла у страницы нет ни на 1440, ни на 390 пикселях.

## Оговорка

«Сифон» — вымышленная марка. Акция, призы, отзывы и характеристики придуманы
для демонстрации и ничего не рекламируют.
