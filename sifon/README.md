# Долька

Промо-лендинг вымышленной газировки на свежевыжатом соке. Статическая страница
без сборки: открывается двойным кликом по `index.html`, кладётся на любой хостинг
как есть.

```
sifon/
├── index.html              вся разметка, включая вектор банки и фруктов
└── assets/
    ├── css/style.css       дизайн-токены и все секции
    ├── js/main.js          прелоадер, слайдер, скролл-хореография, соковыжималка
    └── vendor/             gsap 3.13, ScrollTrigger, lenis 1.3 — локально, без CDN
```

## Дизайн

Светлая фруктовая система: белая бумага, мятные блоки, крупные скругления
(до 44 px), мягкие тени с зелёным подмесом. Фирменный зелёный `#43AE47` держит
интерфейс, а цвет ведёт продукт — каждый вкус приносит тройку `--flavTop`,
`--flav`, `--flavBot` и пастельный `--tint`, которыми разом красятся банка,
заголовок, ореол, пузырьки и подложка секции.

Шрифты: **Pacifico** на логотип и этикетку, **Nunito** на заголовки,
**Alegreya Sans** на текст.

## Как нарисована банка

Внешних картинок на сайте нет ни одной — банка и фрукты собраны вектором
и лежат в самой странице как SVG-символы.

Объём банки даёт не один градиент, а слои:

1. базовая заливка `var(--flav)`;
2. верхний и нижний цвета вкуса, растворённые серыми масками `fadeTop` / `fadeBot`
   — так получается вертикальный двухцветный переход, как на печатной банке;
3. `cylShade` — горизонтальный градиент в одиннадцать стопов: тёмный борт,
   ключевой блик, полутон, контровой блик, тёмный борт. Это и читается как цилиндр;
4. `cylVert` — притенение сверху и снизу;
5. конденсат: около шестидесяти капель, у каждой тень снизу и блик сверху,
   считаются скриптом и обрезаются по силуэту банки;
6. алюминиевая крышка с язычком, донный ободок, контактная тень и отражение
   (зеркальная копия под маской-растворением).

Слои цвета сделаны масками, а не градиентом со стопами: `var()` не разрешается
в атрибутах внутри теневого дерева `<use>`, и банки просто чернели.

## Структура и что происходит при скролле

| Секция | Механика |
| --- | --- |
| Прелоадер | счётчик 0→100, заливка полосы, шторка уезжает вверх |
| Герой | слайдер на пять вкусов: меняются заголовок, двухцветная банка, фрукты вокруг неё, пузырьки и фон блока. Плюс параллакс банки, наклон за курсором и канвас с пузырьками |
| Манифест | секция пинится, три тезиса сменяют друг друга, банка поворачивается по прогрессу |
| Вкусы | пин + горизонтальная лента из пяти карточек, фон перекрашивается в оттенок текущего вкуса |
| Факты | шесть пастельных карточек, счётчики добегают до значений при появлении в кадре |
| Соберите микс | выбор фрукта → струя и наполнение стакана |
| Акция | обратный отсчёт до 31 декабря, проверка кода с язычка |
| Отзывы | две встречные бегущие строки |
| Финал | побуквенный выход крупной надписи, форма заявки с проверкой имени и телефона |
| Подвал | волнистый край, вырезанный белой SVG-шапкой, параллакс крупной подписи |

## Доступность и отказоустойчивость

- `prefers-reduced-motion: reduce` выключает всю хореографию: пин, горизонтальный
  скролл, слайдер и прелоадер отменяются, секции разворачиваются в обычный поток.
- Без JavaScript страница остаётся читаемой — ничего не спрятано за наблюдателями
  скролла, весь контент виден в покое.
- Полоса прогресса в шапке использует нативный `animation-timeline: scroll()`
  там, где он поддерживается, и падает на обработчик скролла там, где нет.
- Клавиатурная навигация: видимый фокус у всех интерактивных элементов,
  `aria-pressed` у кнопок фруктов, `aria-live` у статуса и форм.
- Горизонтального скролла нет ни на 1440, ни на 390 пикселях.

## Производительность

Замеры снимались в Chromium через CDP `Performance.getMetrics`: прокрутка
всей страницы (≈14 700 px) колесом, 260 шагов, с движением курсора по герою.

| Метрика | До | После |
| --- | ---: | ---: |
| Задачи главного потока | 6705 мс | 3973 мс |
| Скрипт | 513 мс | 262 мс |
| Пересчёт стилей | 377 мс | 251 мс |
| Раскладка | 628 мс | 469 мс |
| Раскладок за прокрутку | 512 | 404 |
| Узлов в DOM | 7029 | 4721 |
| Загрузка | 1658 мс | 685 мс |
| Кадров дольше 20 мс | 10 | 1 |
| Худший кадр | 49,9 мс | 33,3 мс |

Что именно стоило дорого:

- `backdrop-filter: blur(14px)` на закреплённой шапке пересчитывал размытие
  всего экрана на каждом кадре прокрутки. Заменён плотным фоном — на белой
  странице разницы не видно;
- `feGaussianBlur` в тени банки и размытие отражения: фильтр пересчитывается
  заново при каждой трансформации, а банка всё время едет, крутится и наклоняется.
  Тень стала радиальным градиентом, отражение — облегчённым силуэтом `#canRefl`
  без капель и обводок;
- `filter: drop-shadow` на фруктах и этикетке: у фруктов бесконечная анимация,
  поэтому тень перерисовывалась каждый кадр. Контраст этикетки теперь держит
  `paint-order: stroke`;
- ширина полосы прогресса в манифесте менялась на каждом тике скраба — это
  раскладка. Переведено на `transform: scaleX()`;
- чтение `scrollHeight` в обработчике прокрутки — принудительный пересчёт
  раскладки на каждом событии. Значение кешируется и обновляется по ресайзу;
- канвас с пузырьками крутился всегда, даже когда герой далеко за экраном.
  Теперь останавливается по `IntersectionObserver`, плотность снижена;
- `ScrollTrigger.refresh()` на каждое открытие вопроса пересчитывал все
  триггеры разом — теперь с задержкой и один раз.

## Проверки

Функциональные и на устойчивость — через Playwright и `@playwright/cli`:

- слайдер вкусов, соковыжималка, обе формы с обоими сценариями валидации, аккордеон;
- `prefers-reduced-motion`: прелоадер скрыт, все тезисы видны, лента вкусов
  разворачивается в столбик, подсказки о слоях сняты;
- без JavaScript: заголовок, девять секций, банка и ответы на вопросы на месте;
- клавиатура: восемь переходов подряд, у каждого элемента видимый фокус;
- консоль чистая; страница проверена и с отключёнными Google Fonts — вёрстка
  не рассыпается, работают запасные гарнитуры.
